Smart Task Manager — حزمة التطبيق الشخصي
النسخة: v0.3.2.105

المحتويات:
- index.html: نسخة النشر المهيأة للتثبيت (أُبقي ملف المصدر المعتمد خارج هذه الحزمة دون تغيير).
- manifest.json: بيانات التطبيق وأيقوناته وسلوك عرضه.
- service-worker.js: تخزين موارد التطبيق مؤقتًا لتوفير دعم محدود للعمل دون اتصال.
- icons/: أيقونات التطبيق.

النشر على GitHub Pages:
1. احتفظ بنسخة احتياطية من المستودع الحالي.
2. ارفع محتويات هذا المجلد إلى جذر المستودع الذي يخدم GitHub Pages، بحيث يكون index.html في الجذر.
3. انتظر اكتمال النشر وافتح رابط الموقع عبر HTTPS.
4. اختبر التطبيق أولًا في المتصفح، ثم استخدم خيار التثبيت/الإضافة إلى الشاشة الرئيسية.
5. اختبر الوظائف والبيانات على جهازك قبل اعتماد الحزمة نهائيًا.

تنبيهات:
- هذه الحزمة لا تضيف حسابات مستخدمين أو مزامنة سحابية؛ البيانات الحالية تبقى في تخزين المتصفح/الجهاز.
- قد تتطلب بعض وظائف التطبيق اتصالًا بالإنترنت، لذلك لا يعني التخزين المؤقت أن كل الوظائف تعمل دون اتصال.
- يلزم اختبار التثبيت الفعلي في المتصفح والجهاز المستهدفين.
